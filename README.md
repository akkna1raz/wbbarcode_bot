(ВАЖНО!!! НЕ ЗАБУДЬТЕ!!!)

Сейчас в коде авторизация работает в гибридном режиме:

Если запрос идёт из Telegram, то приложение проверяет подлинность сессии через криптографическую подпись.

Если запрос открыт по прямой ссылке в браузере или локально, то он всё равно отрабатывает, а не падает с ошибкой доступа.

Это сделано для тестов!!!

Как включить режим для продакшена:

В файле backend/core.js найдите в самом начале проверку авторизации и замените мягкое условие на строгое:



// Было (режим разработки):

if (botToken \&\& tgInitData) {

&#x20; const isValid = await validateTgInitData(tgInitData, botToken);

&#x20; if (!isValid) { ... }

}



// Стало (ТОЛЬКО из Telegram):

if (!botToken || !tgInitData || !(await validateTgInitData(tgInitData, botToken))) {

&#x20; emit('error', { error: 'unauthorized', message: 'Запуск разрешён только внутри Telegram' });

&#x20; return;

}



После этого никто не сможет обратиться к бэкенду в обход Telegram.





Список инструментов и сервисов:



Для сканирования штрихкодов использую BarcodeDetector плюс запасной модуль Html5Qrcode, быстро считывает штрихкод на аппаратном уровне, а для старых и слабых устройств включается резервная библиотека.



Yandex Search API использую для самого лучшего возможного поиска, читает только лучшие сайты игнорирую сайты с мусором и продажей самих штрихкодов.



Нейросеть YandexGPT использую LLM модель для обработки текстом для лучшего результата поиска на вб вычищая мусор из названия (потому что одними алгоритмами не обойтись).



Внутренний поиск Wildberries здесь я забираю 30 товаров из поиска из поиска, нахожу лучший вариант и узнаю цены с учетом скидок.



База данных Redis чтобы повторно не обращаться к платным сервисам, хранит старые сканированные товары и возвращает их проверяя нынешнюю цену.





Как устроен алгоритм сопоставления товаров:



Формирую короткий запрос ( бренд + модель + ключевые слова ) чтобы не сломать поиск длинным запросом к вб, после с помощью медианы цен, среднего типа товаров, в соответствие поиску выбираю нужный товар через кучу алгоритмов, убирая не нужный товар например чехлы (ну если конечно товар не сам чехол), перед этим я очищаю слова от мусора (знаков препинания, не правильного написания и тд). Использую проверку категории, веса и комплектации чтобы минимизировать не совпадение товара (чуть ослабил чтобы не душить нужные товары, но в реальных тестах не попадается 4 шт вместо 2), ну и в конце сортирую карточки по цене и совпадениям и возвращаю пользователю





Защита от ошибок и сбоев:



Подтверждает штрихкод по 2 кадрам чтобы не путался штрихкод. Защищаю базу Редис на 30 сек если пользователь спамить запросами. Сделал понятные статусы для ошибок. Сделал выдержку пауз между запросами или блокировок со стороны вб чтоб не ломать приложение. Приложение контролирует чтобы камера не зависла или чтобы точно что-то вернула если у пользователя пропал интернет на время (в случае других багов надо просто перезагрузить приложение)



Запуск: 



1\. Токен бота Телеграм (TG\_BOT\_TOKEN) - Нууу тут и так понятно...



2\. Идентификатор каталога Яндекса (YANDEX\_FOLDER\_ID)

Где брать: в личном кабинете облака Яндекс Клауд (console.yandex.cloud).

Пошаговые действия:

Перейдите на сайт console.yandex.cloud и войдите под вашим Яндекс логином.

Если вы заходите впервые, сервис предложит создать платежный аккаунт. Новым пользователям дают 4000 руб на 2 месяца за привязку карты.

В левом верхнем углу вы увидите имя вашего рабочего пространства и каталог. По умолчанию он называется default.

Нажмите на этот каталог. В шапке страницы или в блоке О каталоге вы увидите поле Идентификатор.

Это строка из латинских букв и цифр вида b1g.... Скопируйте ее, это ваш YANDEX\_FOLDER\_ID.



3 и 4. Ключи для Поиска и Нейросети (YANDEX\_SEARCH\_API\_KEY и YANDEX\_GPT\_API\_KEY)

Лайфхак: эти два ключа можно получить одновременно через один сервисный аккаунт, поэтому сам ключ будет одним и тем же для обеих переменных.

Пошаговые действия:

В консоли Яндекс Клауд внутри вашего каталога в левом меню откройте раздел Сервисные аккаунты. (вот тут могут быть проблемы, если нужна помощь я могу помочь создать)

Нажмите кнопку Создать сервисный аккаунт.

Придумайте понятное имя.

Ниже найдите пункт Добавить роли и выдайте две роли:

Первая роль для поиска: search-api.webSearch.user

Вторая роль для нейросети: ai.languageModels.user

Нажмите Сохранить.

Теперь в общем списке сервисных аккаунтов кликните на созданный сервисный аккаунт.

Вверху нажмите Создать новый ключ и выберите Создать API ключ.

На экране появится сгенерированный ключ вида AQVN....

Обязательно сразу скопируйте его и сохраните в блокнот!!! Потому что Яндекс показывает его только один раз. Этот один ключ вставляйте и в YANDEX\_SEARCH\_API\_KEY, и в YANDEX\_GPT\_API\_KEY.

Важная мелочь: в левом меню консоли откройте раздел Search API и нажмите Включить сервис, если он еще не был активирован. (иногда может быть выключенным)



5\. Облачная база данных Редис (REDIS\_URL) Тут вряд ли обьяснение нужно, но создается аккаунта, выбирается фри тариф и получает ссылка типо rediss://default:AbCdEf...@eu-central-1.upstash.io:6379 (ОБЯЗАТЕЛЬНО rediss С ДВУМЯ s ИНАЧЕ НЕ БУДЕТ РАБОТАТЬ НЕ НА ЛОКАЛЬНОМ ХОСТЕ)



6\. Адрес бэкенда для клиентской части (API\_BASE\_URL)

Где брать: это ссылка на опубликованную функцию в Яндекс Клауд, куда фронтенд будет отправлять штрихкоды.

Пошаговые действия:

В консоли Яндекс Клауд в левом меню выберите сервис Cloud Functions.

Нажмите кнопку Создать функцию, укажите имя, например wb-scanner-api.

В открывшемся редакторе выберите среду выполнения Node.js 22+.

В поле Точка входа впишите: ycf.handler.

Загрузите файлы из вашей папки backend в виде ZIP архива.

Чуть ниже в блоке Переменные окружения добавьте все ключи, которые мы собрали в предыдущих шагах:

YANDEX\_FOLDER\_ID

YANDEX\_SEARCH\_API\_KEY

YANDEX\_GPT\_API\_KEY

REDIS\_URL

TG\_BOT\_TOKEN

Нажмите кнопку Сохранить изменения в правом верхнем углу.

На вкладке Обзор включите тумблер Публичная функция, чтобы браузер мог обращаться к ней без сложной авторизации облака. (таймаут надо поставить желательно на 60 сек)

Скопируйте строчку Ссылка для вызова. Она выглядит как https://functions.yandexcloud.net/d4e....

ВАЖНО!!! Откройте файл frontend/config.js и вставьте эту ссылку в поле API\_BASE\_URL.



7\. Прокси для маркетплейса (WB\_PROXY\_URL) эот параметр необязателен.

Нужен для продакшена чтобы не отлетало по 429 за слишком большое кол-во обращений к вб.
